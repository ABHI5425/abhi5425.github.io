How I build with AI

Four beliefs from putting LLMs in front of real users and real queues.

1

Ground it in a source of truth

A model is only as trustworthy as what it retrieves. Index the docs your organization stands behind.

2

Fix problems where they start

Catching a bad ticket in triage is cleanup. Stopping it at creation removes the work.

3

Pick the metric before the model

If we can't say which number moves, we're not ready to build.

4

Keep humans where judgment lives

Automate the repeatable; design clear hand-offs for calls that need a person.
